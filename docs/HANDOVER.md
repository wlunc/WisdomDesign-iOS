## 2. 怎么读（按角色）

### 第一天接手（约 40 分钟）

1. [`../AGENTS.md`](../AGENTS.md) §0–§2 —— 弄清"现在到哪一步、什么不能做"；
2. [`DEV-PLAN.md`](DEV-PLAN.md) **§0 速览** + **§1 本端定位** —— 本端负责 37 件里的哪些、边界在哪；
3. [`DEV-PLAN.md`](DEV-PLAN.md) **§2 M0 本端视图** —— 当前里程碑要做什么、入口判据是什么、出口判据是什么；
4. [`DEV-PLAN.md`](DEV-PLAN.md) **§16 开发者指南** —— 环境、规范、提交、排障、升级路径；
5. 需要动手时再读 **§14 SOP**（从 0 到合并的 8 步）。

### 要开工一个组件（约 15 分钟）

1. `DEV-PLAN.md` **§13.1** 找到该件（批次 / 关键路径件 / 落点 / `SPEC.md` 锚点 / 验收要点 / 依赖）；
2. `DEV-PLAN.md` **§20.2** 查它的**设计编号**与画廊检索词 → 打开设计规格与画廊；
3. `DEV-PLAN.md` **§20.4** 看它的**尺寸 / 变体 / 状态 / 关键令牌**速查；
4. **M2 的 11 件**再过一遍 **§21.5「实现前自检十问」**（答不出就先别写）；
5. `SPEC.md` 对应节 —— 签名与断言的真源；
6. 走 **§14 SOP** 的八步。

### 要结批

`DEV-PLAN.md` **§15 验收手册**（逐批：出口判据 + 可运行命令 + 不通过处置 + 勾选清单）+ **§3 批次分配**（批前签名冻结与出口）。

### 要查设计文档 / 设计图

`DEV-PLAN.md` **§19**（设计仓地图、按任务查、检索命令、冲突处置）+ **§20**（逐组件溯源）。

## 3. 哪些还没验证（**不得当成已通过**）

`DEV-PLAN.md` **§8.1** 与 `../AGENTS.md` §7 是**唯一清单**（U-01…U-09）。摘要：

| 类别 | 内容 |
| --- | --- |
| 工具链全链路 | `xcodebuild` 的完整链路（含覆盖率、`-resultBundlePath`）**本机未跑通**（沙箱阻塞 SwiftPM manifest 缓存） |
| 冒烟首发 | `WDAPISmokeTests` / `#if WD_API_SMOKE` 的签名冒烟**尚未首次执行** |
| 真机视觉 | 真机字体与**自然行盒**、AX3 与 2.0 档观感、玻璃在真机（模拟器不真实） |
| 快照基线 | 六态截图基线**尚未入库**（首版基线由 M1 建立） |
| 体积 | 归档体积增量与体积门槛值（**U-09**，M3 出口） |
| 分发 | SPM tag 实验、发布流程实操 |

**纪律**：这些项在文档里一律标【未验证】；**任何"已通过"的写法都是错的**，除非有实测输出。

## 5. 追溯：文档里出现的"数字代号"是什么

**可解引用入口**：`DEV-PLAN.md` **§17 术语表**（含已退役代号解析）与 **§6 回写项**（P7–P12：改哪个文件哪一节、状态如何）。**施工动作只认**：`SPEC.md`、`../AGENTS.md`、`DEV-PLAN.md` 与外部设计仓。
